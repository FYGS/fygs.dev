# Accessibility audit - October 2026

Target: WCAG 2.2 level AA. Branch `chore/perf-a11y` (from `03729aa`).

## Method

`@axe-core/playwright` and `jest-axe` are not installed (and the shared `node_modules` must not be modified),
but `axe-core@4.14.0` is present in the pnpm store (`node_modules/.pnpm/axe-core@4.14.0`). The audit therefore
injects `axe.min.js` into real Chrome through Playwright:

- `scripts/audit/a11y-audit.mjs <base> <routes.txt> <out.json>`: per route, axe with tags
  `wcag2a, wcag2aa, wcag21a, wcag21aa, wcag22aa, best-practice` + custom checks: `<html lang>`, h1 count,
  landmarks, first focusable element (skip link), a 30-step `Tab` walk (focus indicator present, accessible
  name present, lost focus), and `prefers-reduced-motion: reduce` emulation counting infinite running animations
  (`document.getAnimations()`).
- `scripts/audit/summarize.mjs <out.json> [rule]`: aggregation by rule with the most frequent selectors.
- `scripts/audit/widgets-check.mjs <base>`: keyboard behaviour of the locale modal, the shortcuts dialog, Radix
  tabs and the skip link.
- Production build (`next build --webpack` + `next start -p 3600`), viewport 1280x900, dark theme (the default),
  cookie `locale_selected=true`. The DB is unreachable, so only what renders without it was audited.

Routes (25): `/fr` and `/en` home, `/{fr,en}/blog` + one post, `/{fr,en}/pricing`, `/{fr,en}/contact`,
`/{fr,en}/auth/login`, `/fr/auth/register`, `/fr/auth/forgot-password`, `/fr/projects`, `/fr/community`,
`/{fr,en}/tech-mastry`, `/fr/tech-mastry/frontend`, `/fr/tech-mastry/frontend/accessibility`,
`/fr/tech-mastry/algorithms/sorting`, `/fr/tech-mastry/system-design/scalability` (visualization page),
`/fr/tech-mastry/playground`, `/{fr,en}/privacy`, `/fr/terms`.

Evidence files are regenerated by the scripts; the numbers below come from three production runs
(S1 = after the first round of fixes, S2 = second round, S3 = third round).

### Motion (2.3.3, 2.2.2)

The app had no `prefers-reduced-motion` handling at all (`grep` finds only `reducedMotion: "respect"` in a config object that nothing reads).

- `providers/motion-provider.tsx`: `<MotionConfig reducedMotion="user">` around the whole tree (framer-motion).
- `app/globals.css`: `@media (prefers-reduced-motion: reduce)` collapses CSS animations/transitions and disables smooth scroll (spinners keep rotating).
- Verified with `emulateMedia({reducedMotion:'reduce'})`: 0 infinite animations on all 25 routes, except two `animate-spin` loading spinners on the playground while it boots (kept on purpose: they convey progress).

### Focus and widgets (2.1.1, 2.1.2, 2.4.3, 2.4.7)

- Focus indicator: on 30 `Tab` stops per page, 0 stops without outline/box-shadow on all 25 routes; 0 lost focus.
- Locale modal (Radix dialog): has a name and a description, focus stays inside for 12 `Tab` presses, `Escape` closes.
- Shortcuts dialog (`?`): focus moves in, `Escape` closes. Focus goes back to `body` because it was opened from the page (acceptable).
- Tabs (Radix): `ArrowRight` moves to the next tab, `aria-selected`, one `tabpanel`.
- Playground command palette: was a hand-rolled overlay (no `role="dialog"`, no name, `Escape` did nothing, focus not restored). Now `role="dialog" aria-modal`, named, `Escape` closes, focus returns to the previously focused element.

### Tests

`tests/unit/components/ui/a11y-primitives.test.tsx` (role/name queries in jsdom): skip link name per locale and visual hiding; `FieldError`/`fieldErrorProps` association (`toHaveAccessibleDescription`); password toggle name per state/locale.

## Re-running

```
node node_modules/next/dist/bin/next build --webpack && node node_modules/next/dist/bin/next start -p 3600
node scripts/audit/a11y-audit.mjs http://localhost:3600 scripts/audit/routes-a11y.txt out.json 30
node scripts/audit/summarize.mjs out.json
node scripts/audit/widgets-check.mjs http://localhost:3600
```

Under Git Bash set `MSYS_NO_PATHCONV=1` (a leading `/` in a route is otherwise rewritten to a Windows path) and
use a Windows path for the output file (`C:/tmp/out.json`).
